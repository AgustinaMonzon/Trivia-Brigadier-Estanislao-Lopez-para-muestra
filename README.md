# Trivia Federal: Brigadier Estanislao López

Aplicación web interactiva de trivia histórica pensada para el aula y la muestra escolar de fin de año. Es el producto final de una investigación realizada por los estudiantes de **6.º grado** de la **Escuela N.º 1279 "Brigadier Estanislao López"** de la ciudad de **Rosario** (Santa Fe, Argentina), programada por su docente **Agustina Monzón**.

## Contexto pedagógico
- **Nivel y grado:** 6.º grado de educación primaria.
- **Institución:** Escuela N.º 1279 "Brigadier Estanislao López", Rosario.
- **Autoría y programación:** Agustina Monzón (docente a cargo), a partir del trabajo y la investigación del grado.
- **Instancia de presentación:** Muestra escolar de fin de año.

## Características principales
- **10 preguntas de opción múltiple** sobre Estanislao López, el federalismo, los acuerdos interprovinciales y el análisis de fuentes históricas, con retroalimentación inmediata (cartel de acierto o reintento).
- **Sonidos integrados** generados con Web Audio API para respuestas correctas e incorrectas.
- **Diseño adaptable (responsive)** para escritorio, tablet y celular.
- **Proyecto estático** construido con HTML, CSS y JavaScript puro, sin dependencias externas.

## Estructura del proyecto
- `index.html`: estructura, estilos y lógica del juego.
- `foto1.png` – `foto10.png`: ilustraciones históricas asociadas a cada consigna.

## Despliegue
El proyecto está alojado en GitHub y desplegado de forma continua en Vercel a partir de la rama `main`.

## Uso en clase o muestra
1. Abrir el enlace desplegado en el navegador de una tablet, computadora o celular.
2. Responder cada consigna seleccionando una opción (`A`, `B`, `C` o `D`).
3. Usar el botón de reinicio al finalizar para volver a jugar con otro grupo o visitante de la muestra.
